## 原生 IP、家宽 IP、双 ISP 到底差在哪

这三个词经常被混着用，实际是三件事。

**原生 IP** 说的是归属地和服务器所在地一致。马来西亚的服务器配马来西亚注册的 IP，就算原生。这个定义只能排除“拿美国 IP 冒充马来西亚”的情况，说明不了 IP 是住宅还是机房。朝暮数据的帮助页给的口径也是这个意思：IP 运营商所在国家和服务器地理位置一致。

**家宽 IP** 才涉及用途属性。它来自 ISP 分配给家庭用户的地址段，平台查到的 ISP 名称是本地宽带运营商，而不是某个数据中心。这才是 TikTok 这类平台真正会看的东西。

**双 ISP** 指线路背后有两家运营商接入，单条线路抖动时不至于整个掉线。它是稳定性设计，和 IP 是不是住宅没有必然关系。

落到可验证的指标上，只有三样值得看：ASN 编号、ISP 名称、IP 类型标注。第三方工具对 WePC 马来西亚这档的检测结果是 AS56286、运营商 IX Telecom、归属地霹雳州怡保，pingip.cn 与 ping0.cc 都判定为原生家庭宽带 IPv4。

这个结果只能代表那一次分到的 IP 段。另一篇第三方测评里，同一产品的 IP 被记为从 Gigabit Hosting 和本地 ISP 分配，和 AS56286 对不上。真实家宽资源是按段采购的，不同批次落在不同运营商身上很正常，别把某一次的 ASN 当成永久承诺。双 ISP 属性在不同 IP 数据库里也可能判定不一致，买之前用 pingip.cn 之类工具自己查一遍最稳。

还有那个“风控风险评分 10%”。它是第三方检测工具给出的数字，不是 TikTok 官方评分，也不能拿来推算封号概率。朝暮数据的帮助页甚至直接说，某些网站提供的 IP 欺诈值检测没有评分依据，IP 地址本身也没有“纯净、干净、新老”的官方说法，平台有自己的 IP 库和检测手段。你可以把 10% 当参考，真正能核的是 ASN、ISP 归属和住宅属性这三项。
